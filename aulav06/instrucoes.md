# Exercício: Consulta de previsão do tempo

Você deverá criar uma pequena aplicação web em Python que consulte uma API de previsão do tempo e apresente os resultados em uma página HTML.

## Objetivos

Ao finalizar o exercício, o aluno deverá praticar:

Consumo de uma API utilizando Python.
Uso de listas para armazenar informações.
Uso de tuplas para representar dados relacionados.
Manipulação de dados retornados em formato JSON.
Integração entre Python e HTML.

## Situação-problema

Uma empresa deseja disponibilizar em seu site uma consulta simples de previsão do tempo.

O usuário deverá informar o nome de uma cidade. O programa Python fará uma requisição para uma API de clima e exibirá na página:

Cidade;
Temperatura atual;
Sensação térmica;
Umidade;
Condição do tempo;
Previsão para os próximos dias.
