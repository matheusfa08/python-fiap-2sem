# 🔄️ Interação com Banco de Dados

## 📖 A teoria por trás

A máquina se comunica com o Banco e dados através do *DataSource* e do *DataSet.*

***DataSoure***
    
    Manda os dados da aplicação para o BD

***DataSet***

    Manda os dados do BD para a aplicação

## O Oracle:

Precisamos fazer a importação de duas bibliotecas: **Pandas** e **OracleDB**
