# 📋 ***API (Aplication Programming Interface)***

## 💬 **Por que devo usar?**

Pois a *API* trás, além de novas informações e
novas aplicações, uma facilidade a mais, não tendo 
que criar novas listas.

## 🐍 **O que é necessário para usar no Python?**

As bibliotecas para a aplicação das *APIs* não 
estão instaladas nativamente, por isso...

**Use o seguinte comando:**
    
    pip install requests
